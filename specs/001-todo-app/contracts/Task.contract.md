# Task Model Contract

**Feature**: 001-todo-app
**Date**: 2025-10-24
**Purpose**: Task entity model with validation and business logic

## Overview

`Task` is a model class representing a single to-do item. It encapsulates validation rules, state transitions, and provides a clean API for task operations.

## Interface

### Constructor

```javascript
/**
 * Creates a new Task instance
 *
 * @param {Object} data - Task data
 * @param {number} [data.id] - Task ID (generated if not provided)
 * @param {string} data.title - Task title (1-500 characters)
 * @param {boolean} [data.completed=false] - Completion status
 * @param {number} [data.createdAt=Date.now()] - Creation timestamp
 * @param {number} [data.updatedAt=Date.now()] - Update timestamp
 * @throws {ValidationError} If data is invalid
 */
constructor(data)
```

**Validation Rules**:
- `title`: Required, 1-500 characters after trim (VR-001, VR-002)
- `completed`: Boolean, defaults to false
- `createdAt`: Positive number, defaults to current time
- `updatedAt`: Positive number, >= createdAt, defaults to current time
- `id`: Positive integer if provided

**Example**:
```javascript
// Minimal task
const task = new Task({ title: "Buy groceries" });
// { id: undefined, title: "Buy groceries", completed: false, createdAt: ..., updatedAt: ... }

// Full task
const task = new Task({
  id: 42,
  title: "Buy groceries",
  completed: false,
  createdAt: 1729785600000,
  updatedAt: 1729785600000
});
```

**Error Cases**:
```javascript
// Empty title
new Task({ title: "   " });
// Throws: ValidationError("Task title cannot be empty")

// Too long
new Task({ title: "x".repeat(501) });
// Throws: ValidationError("Task title cannot exceed 500 characters")

// Invalid completed
new Task({ title: "Valid", completed: "yes" });
// Throws: ValidationError("Completed must be a boolean")
```

#### completed

```javascript
/**
 * Task completion status
 * @type {boolean}
 */
get completed()
set completed(value)
```

**Validation on set**:
- Must be boolean
- Throws `ValidationError` if not boolean

**Side effects**:
- Automatically updates `updatedAt` timestamp

**Example**:
```javascript
task.completed = true;   // OK, marks as complete
task.completed = false;  // OK, marks as incomplete
task.completed = "yes";  // Throws ValidationError
```

### Methods

#### markComplete

```javascript
/**
 * Marks the task as complete
 * @returns {void}
 */
markComplete()
```

**Preconditions**: None

**Postconditions**:
- `completed` is `true`
- `updatedAt` is set to current time

**Example**:
```javascript
task.markComplete();
console.log(task.completed);  // true
```

---

#### markIncomplete

```javascript
/**
 * Marks the task as incomplete
 * @returns {void}
 */
markIncomplete()
```

**Preconditions**: None

**Postconditions**:
- `completed` is `false`
- `updatedAt` is set to current time

**Example**:
```javascript
task.markIncomplete();
console.log(task.completed);  // false
```

---

#### toggle

```javascript
/**
 * Toggles completion status
 * @returns {void}
 */
toggle()
```

**Preconditions**: None

**Postconditions**:
- `completed` is inverted (true → false, false → true)
- `updatedAt` is set to current time

**Example**:
```javascript
console.log(task.completed);  // false
task.toggle();
console.log(task.completed);  // true
task.toggle();
console.log(task.completed);  // false
```

---

#### update

```javascript
/**
 * Updates task properties
 *
 * @param {Object} updates - Properties to update
 * @param {string} [updates.title] - New title
 * @param {boolean} [updates.completed] - New completion status
 * @throws {ValidationError} If updates are invalid
 * @returns {void}
 */
update(updates)
```

**Preconditions**:
- `updates` is an object with at least one property

**Postconditions**:
- Specified properties are updated
- `updatedAt` is set to current time
- Validation rules applied

**Example**:
```javascript
task.update({ title: "Buy groceries and milk" });
task.update({ completed: true });
task.update({ title: "New title", completed: true });
```

**Error Cases**:
```javascript
task.update({ title: "" });
// Throws: ValidationError("Task title cannot be empty")
```

### Static Methods

#### validate

```javascript
/**
 * Validates task data without creating instance
 *
 * @param {Object} data - Task data to validate
```

**Returns**:
```javascript

  valid: true,
  errors: []
}
```

**Example**:
```javascript

  console.error('Validation errors:', result.errors);
```

## Validation Rules

Based on functional requirements and data model:

| Rule ID | Rule | Error Message |
|---------|------|---------------|
| **VR-001** | Title required (after trim) | "Task title cannot be empty" |
| **VR-002** | Title length 1-500 characters | "Task title cannot exceed 500 characters" |
| **VR-003** | Completed is boolean | "Completed must be a boolean" |
| **VR-004** | Timestamps valid | "updatedAt must be >= createdAt" |
| **VR-005** | ID is positive if provided | "Task ID must be a positive integer" |

## State Transitions

### State Diagram

```
┌─────────────┐
│  Incomplete │
│ (new Task)  │
└──────┬──────┘
       │
       │ markComplete() / completed = true
       ├─────────────────────────┐
       │                         │
       ▼                         │
┌─────────────┐                  │
│  Completed  │                  │ markIncomplete() / completed = false
└──────┬──────┘                  │
       │                         │
       └─────────────────────────┘
```

### Transition Rules

1. **Create** → Always starts as incomplete
2. **markComplete** → Changes state to complete, updates timestamp
3. **markIncomplete** → Changes state to incomplete, updates timestamp
4. **toggle** → Flips state, updates timestamp
5. **update** → Can change state via `completed` property

## Usage Examples

### Creating Tasks

```javascript
// Simple task
const task1 = new Task({ title: "Buy groceries" });

// Task with completion
const task2 = new Task({
  title: "Call dentist",
  completed: true
});

// Task with all fields
const task3 = new Task({
  id: 42,
  title: "Important task",
  completed: false,
  createdAt: Date.now() - 86400000,  // 1 day ago
  updatedAt: Date.now()
});
```

### Updating Tasks

```javascript
// Update title
task.title = "Buy groceries and milk";

// Mark complete
task.markComplete();

// Toggle completion
task.toggle();

// Batch update
task.update({
  title: "New title",
  completed: true
});
```

### Validation

```javascript
// Pre-validate before creating
const result = Task.validate({
  title: "",
  completed: "yes"
});

if (!result.valid) {
  console.error('Invalid task:', result.errors);
} else {
  const task = new Task(data);
}
```

### Serialization

```javascript
// To JSON
const json = task.toJSON();
const jsonString = JSON.stringify(task);

// From JSON
const task = Task.fromJSON(json);
```

## Error Handling

### ValidationError

```javascript
class ValidationError extends Error {
  constructor(message) {
    super(message);
    this.name = 'ValidationError';
  }
}
```

**When thrown**:
- Invalid title (empty or too long)
- Invalid completed value (not boolean)
- Invalid timestamps (updatedAt < createdAt)
- Invalid ID (not positive integer)
